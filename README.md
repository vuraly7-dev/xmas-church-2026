一個從兩千年前伯利恆傳來的好消息，一站一站傳到你手上。
走一趟牧羊人的聖誕夜（路加福音 2:8–17），留下你的名字與祝福，再把佳音傳下去。

「爬上聖誕樹」：7 道聖誕節的聖經題目，答對一題往上爬一層，到樹頂點亮星星，領取可下載保存的祝福經文圖卡。

本專案為原創互動作品，中文經文引自《和合本》聖經；「爬上聖誕樹」的英文祝福經文引自 King James Version（KJV，公有領域）。
背景音樂為公有領域的聖誕詩歌旋律（〈平安夜〉1818、〈普世歡騰〉1839），由網頁程式即時合成，不含任何錄音檔。
遊戲不會收集或儲存任何資料；名字與祝福只存在分享連結中。
